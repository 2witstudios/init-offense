# Delivery plan template

Owner objective and existing authorization; acceptance criteria; concrete leaf
manifest (ID, owner, outputs, build inputs, accepts after); pinned provisional
producer source SHAs and contracts; actual writer collisions; decisions; proof
obligations (candidate, check, state, reason, responsible agent, discharge point);
remaining work and context handoff. Keep a single durable delivery record.
Ready means useful authorized branch work can proceed. Done requires independent
acceptance. A plan-only request stays plan-only. Planning and administration do
not require reauthorization of an implementation instruction.
